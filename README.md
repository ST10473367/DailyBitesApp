This project is about creating an Application that gives food suggestions for specific meal times in the day.
The Application will help the user to be able to make a decision on what food they would like to eat as there will be suggestions available to them instead of thinking about what to eat.
The user will have to input the time of day it is in the place provided (Example: morning , mid morning , afternoon , mid afternoon, evening)
once  user enters the time of the day , thereafter they can click on to the suggestion button which will then give the results of different meals for the user to make there decision
if the user inputs the wrong time of day , the application will give a notification stating they put an invalid input and please can they input a valid time of day.
if the user wants to clear out the input and start again , they can do this by pressing the reset button.
